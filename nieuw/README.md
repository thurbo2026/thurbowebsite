# Nieuwe projecten

Zet hier het materiaal voor een nieuw project neer. Claude maakt er een projectpagina van.

## Zo werkt het

1. Maak per project een eigen map, bijvoorbeeld `nieuw/2026-woontoren-delft/`.
2. Zet daarin:
   - een **pdf** van het project (exporteer InDesign of PowerPoint als pdf; een .indd- of .pptx-bestand kan niet worden gelezen),
   - eventueel losse **beelden** in hoge kwaliteit (jpg of png),
   - eventueel een kort tekstbestand met wat niet in de pdf staat: wie het ontwierp (Thorben, Beau of allebei), jaar, plaats, begeleiders.
3. Vraag Claude: *"Verwerk de nieuwe projecten in de map nieuw."*

Claude haalt de beelden en tekeningen eruit, schrijft de projecttekst in het Nederlands en het Engels,
zet het project in `content/site.json` en verplaatst de map daarna naar `nieuw/verwerkt/`.

Uploaden kan op github.com: open deze map, klik op *Add file* en daarna *Upload files*.
Bestanden groter dan 25 MB passen niet via de website; verklein de pdf dan eerst.
